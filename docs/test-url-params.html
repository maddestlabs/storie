📄 Demo Files

Load local demo files using ?content=demo:name

demo:simple demo:hooks demo:frontmatter

🌐 GitHub Gists

Load content from GitHub gists using ?content=gist:ID

Try creating your own gist with a .md file and add the gist ID here!

Example pattern:

?content=gist:ID

🔗 Full GitHub URLs

Also works with full gist URLs:

?content=https://gist...

💾 LocalStorage

Load from browser storage using ?content=browser:key

First save something to localStorage (open console):

localStorage.setItem('storie_test', '# Test\n\n```javascript on:render\nterm.text(5, 5, "From localStorage!", "#ff00ff");\n```');

?content=browser:test

📝 How to Create a Test Gist

  1. Go to gist.github.com
  2. Create a new gist with a .md file
  3. Add some S|torie content with lifecycle hooks: 
    ```javascript on:render
term.clear();
term.text(5, 5, "Hello from Gist!", "#00ff00");
```
  4. Copy the gist ID from the URL
  5. Use it: ?content=gist:YOUR_ID
